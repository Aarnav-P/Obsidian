I used the battery test data to pull out some angular velocity data. As expected, the bug is going slower when it is turning more. This perhaps implies that there is some $v_\parallel$ and some $v_\perp$ , and that turning is caused  by a decrease in $v_\parallel$ whilst $v_\perp$ remains somewhat constant. And perhaps what is happening is that there is some $v^{(1)} = v^{(1)}_\parallel + v^{(1)}_\perp$ and some $v^{(2)} \approx v^{(2)}_\perp$ such that $v_{total} = v^{(1)} + v^{(2)}$. And the mode of motion that produces $v^{(1)}$ is damped by friction and causes a drop in the parallel motion, which causes greater turning. If this were the case, how would one isolate the perpedicular component of turning?  Perhaps it could be useful as a model since omega seems to flatten out.
