I want to check how the harness and chain are linked. I can imagine that the stress behaves differently with these glued linkages. Actually maybe not, because the hexbug provides rigidity there.

In any case, what is the shortest chain we can see oscillations with; how can I predict $\sigma$; what is their chain design.

First thing is to design the chain again using the original files. They are in .stl so we take them into blender, chop them up and make .obj's. But these still cannot be drawn on in Onshape so then we essentially trace over them with a sketch. In any case, this gives me control over the width properly.

Having done this, we need to establish what the proper imensions are. Fig2d of Zheng shows us that $\ell$ ought be treated as the unit cell width essentially, the distance between Hexbug COMs. (but the pendulum weights are more like the midpoint of the linkage).
![[Pasted image 20261102161201.png|311]]

Now we can design to the same lengthscale (ish) as Eloi.
![[Pasted image 20261102161243.png|466]]

The important thing here is that the width is tunable, the length doesn't matter as long as it gets overlapped by the next bug's frame.

So, Eloi estimates with TPU 95A HF, $\ell =55$mm, that he gets [[Intern Report|(with a factor 2 error?)]]] 0.013 for his elastoactive parameter. I think its probably half that, which means we have work to get to             $\sigma_C=0.16$.. This makes $L$ = $\ell - \text{hexbug length}=7$mm

With [[Bambu_TPU_95A_HF_Technical_Data_Sheet.pdf|TPU 95A HF]] we get a Young's Modulus of 9.8±0.7 MPa and with [[Bambu_TPU_85A_Technical_Data_Sheet_a7233668-497b-487f-af8a-3adb49fafaa1.pdf|| TPU 85A]] , which is the softest TPU available, we have E = 6.8 ± 0.7 MPa

**Given that $C = EJ/L$, where $J$ is a torsional constant, this nets us only a 1.44x improvement. To reach $\sigma_C$ we need something on the order of an 10x increase.**

Ok, so this is one source of improvement. Current $L = 7$mm so we can also improve this a bit, but if we extend it too much does the model still work? 

We can also modify $J$. $J = w^3h\left(\dfrac{16}{3} - 3.36\dfrac{2}{h}\left(1-\dfrac{w^4}{12h^4}\right)\right)$ . $h=2$ mm but we can print as low as 0.2mm in theory.

$$J \downarrow \quad \Rightarrow C \downarrow \quad\Rightarrow \sigma \uparrow$$
